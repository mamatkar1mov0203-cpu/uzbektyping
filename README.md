# UzbekTyping

O‘zbekcha matnlar bilan yozish tezligi va aniqligini sinash uchun yengil, responsiv typing-test sayti. Monkeytype’dan ilhomlangan, mustaqil dizayn va kod.

## Ishga tushirish

`index.html` faylini brauzerda oching. Alohida build yoki dependency talab qilinmaydi.

## Imkoniyatlar

- Vaqt bo‘yicha test: 15, 30, 60 yoki 120 soniya.
- So‘zlar bo‘yicha test: 10, 25, 50 yoki 100 so‘z.
- WPM va test yakunida aniqlik, to‘g‘ri belgilar hamda xatolar statistikasi.
- Tinish belgilarini yoqish, yorug‘/qorong‘i mavzu va tez qayta boshlash.
- Mobil ekranlarga moslashuvchan interfeys.

## Boshqaruv

- Matn maydoniga bosib yoki istalgan tugmani bosib yozishni boshlang.
- `Tab` + `Enter` — testni qayta boshlash.

Matnlar va interfeys o‘zbek tilida.
